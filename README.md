# Git Repository from Scratch

A Python utility project for demonstrating Git initialization, status, staging, commits, history, diff, ignored files and pushing to GitHub.

## Modules
- `calculator.py`: basic arithmetic and zero-division protection.
- `student.py`: student record and average marks.
- `text_utils.py`: reusable text functions.
- `main.py`: runs demonstrations of the other three modules.

## Run
```bash
python3 main.py
```

## Git commands demonstrated
`git init`, `git status`, `git add`, `git commit`, `git log`, `git diff`, `git check-ignore`, `git remote add`, `git push`.

## Learning objective
Create at least five meaningful commits locally and publish their complete history on a public GitHub repository.
